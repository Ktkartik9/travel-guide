# 🌍 City Explorer Project

A smart travel web application that helps users explore any city easily.  
Just search for a city name, and the app instantly shows:

- 🏞 Famous tourist places  
- 🖼 Beautiful location images  
- 🏨 Hotels for stay  
- 💰 Estimated budget for travel  

This project is built using APIs to provide real-time city exploration data and improve the travel planning experience for users.

---

# 🚀 Features

- 🔍 Search any city instantly
- 🏞 Explore popular tourist attractions
- 🖼 View beautiful city/location images
- 🏨 Discover hotels in that city
- 💰 Predefined budget estimation for travelers
- ⚡ Fast and responsive UI
- 🌐 API-based dynamic data fetching

---

# 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- API Integration
- Git & GitHub

---

# 💡 How It Works

1. User searches for a city
2. APIs fetch:
   - Tourist places
   - Images
   - Hotel information
3. The app displays all details dynamically
4. A default travel budget is also shown to help users estimate expenses

---

# 🎯 Purpose of Project

The main goal of this project is to help normal users explore a city easily before traveling.  
It provides quick information about places to visit, hotels, and estimated budget in one platform.
